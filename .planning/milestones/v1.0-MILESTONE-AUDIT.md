## Tech Debt Detail

### Phase 02

**BLOCKER-04 — validate_code_format Unicode-Lookalike-Bug**
- Bekannter Spec-Divergenz-Bug aus Code Review
- Aktuelles Verhalten: `c as u8` truncation lässt Unicode-Chars mit low-byte im Crockford-Alphabet durch
- Beispiel: `Ā = U+0100` hat low-byte `0x00 = '0'` → wird als gültig-formatiert behandelt → 404 (unbekannt) statt 400 (invalid format)
- **Kein Security-Bug** (hash unterscheidet sich, kein Bypass)
- Fix klar: `CROCKFORD_CHARS.contains(c)` statt byte-cast
- **Decision pending:** Bug beheben (ändert 404→400 für Non-ASCII) oder als akzeptiert dokumentieren

**BLOCKER-02 — PRAGMA foreign_keys nicht im Production-Pool**
- FK-Constraints in Migration 20260503000000_create_helper_token_table.sql
- DAO-Unit-Tests setzen `PRAGMA foreign_keys=ON`, E2E und Production aber nicht
- Auswirkung: FKs sind Dokumentation ohne Runtime-Enforcement in Production
- Fix: PRAGMA beim Pool-Setup in `genossi_bin` setzen
