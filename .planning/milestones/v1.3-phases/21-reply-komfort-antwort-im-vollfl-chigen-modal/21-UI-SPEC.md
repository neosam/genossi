## Component & Interaction Contract (load-bearing — phase-specific)

This section pins the locked interaction decisions so the executor implements them without re-deriving from CONTEXT.

**Close affordances (D-01, D-02, D-03):**
- `InboxReplyForm` renders its OWN header as the first child, exactly matching `membership_adjust_modal.rs:142-153`:
  - container: `div { class: "flex items-center justify-between border-b border-gray-200 pb-3" }`
  - title: `h2 { class: "text-xl font-semibold text-gray-900", "{title}" }`
  - X-button: `button { r#type: "button", class: "text-gray-500 hover:text-gray-700 px-2 py-1", onclick: → attempt_close, "\u{2715}" }`
- A second explicit "Abbrechen" button lives in the form footer (neutral styling, NOT accent), also wired to `attempt_close`.
- NO backdrop-click close, NO Escape close (`Modal` has no such handler; do not add one).
- All `r#type: "button"` to avoid the known Dioxus form-reload bug (project memory `feedback_dioxus_button_type`).

**Open/close wiring (D-10):**
- `inbox_page.rs` toggle button opens the modal via `show_reply.set(true)`; label simplifies toward just "Antworten".
- Page composes: `Modal { InboxReplyForm { …, on_close: move |_| show_reply.set(false) } }`.
- Successful send keeps the existing `on_sent` path (info toast, reload, `load_detail`, `show_reply.set(false)`).

**Dirty-check (D-04, D-05, D-06):**
- `attempt_close` = pure helper + closure: if `dirty(subject, body, baseline_subject, baseline_body)` → show discard confirmation; else close immediately.
- Baseline (`baseline_subject` / `baseline_body`) is captured AFTER the async footer load in the SAME `use_effect` that composes the initial body — never against the first-quote value.
- `dirty(...)` is a pure, unit-tested function (`reply_subject != baseline_subject || reply_body != baseline_body`), added alongside the existing `build_original_quote` / `compose_initial_body` tests in `reply_form.rs`. CLAUDE.md requires tests for this change.

**Editor sizing (D-08):** `MailBodyEditor` stays `h-40`. The "roomier" feel comes solely from the `Modal` layout (`max-w-3/4 max-h-[90vh] overflow-y-auto p-8`). Do not add a height prop.
