# Quick Task 260603-hw7 — Konfigurierbares Environment-Label im Menü

## Problem

Das Frontend zeigt im Menü neben „Genossi" das Label aus `config.env_short_description` (Default `"DEV"`), solange `config.is_prod` nicht `true` ist. Im Stable-Release läuft genau die gleiche WASM-Bundle-Datei wie in Dev — das angezeigte Label entsteht ausschliesslich aus `/config.json`, das von `module.nix` erzeugt wird.

Aktuell schreibt `module.nix` nur `{"backend": "..."}` in die `config.json` — daher greifen für `application_title`, `is_prod`, `env_short_description` immer die Frontend-Defaults und die Stable-Instanz heisst weiterhin „Genossi DEV".

## Scope

- module.nix bekommt drei neue, instanz-spezifische Options:
  - `applicationTitle` (str, default `"Genossi"`)
  - `isProd` (bool, default `false`)
  - `envShortDescription` (str, default `"DEV"`)
- Der `environment.etc."genossi-${name}/config.json".text`-Block stellt auf `builtins.toJSON` um, sodass alle vier Felder sauber gequotet ins `config.json` wandern.
- Defaults entsprechen exakt dem heutigen sichtbaren Verhalten (Menü zeigt „Genossi DEV"). Kein Bestandskunde sieht durch das Upgrade ein anderes Label.
- Stable-Deployments können nun in ihrer NixOS-Konfig setzen:
  ```nix
  services.genossi.prod = {
    enable = true;
    isProd = true;            # → DEV-Suffix wird ausgeblendet
    # oder, falls man weiter ein Label will:
    envShortDescription = "PROD";
  };
  ```

## Tasks

### Task 1 — module.nix erweitern

**Files:** `module.nix`

**Action:**
1. Im `options.services.genossi`-Submodule drei neue `lib.mkOption`-Einträge ergänzen (zwischen `extraEnvironment` und `oidc`):
   - `applicationTitle` — `lib.types.str`, default `"Genossi"`, description „Application title shown in the frontend title bar / browser tab"
   - `isProd` — `lib.types.bool`, default `false`, description „If true, the environment short description is not shown next to the title"
   - `envShortDescription` — `lib.types.str`, default `"DEV"`, description „Short environment label shown next to the title when isProd is false (e.g. DEV, STAGING, PROD)"
2. Im `environment.etc`-Block den `text`-Literal-String ersetzen durch:
   ```nix
   text = lib.mkIf instanceCfg.enable (builtins.toJSON {
     backend = "https://${instanceCfg.domain}/api";
     application_title = instanceCfg.applicationTitle;
     is_prod = instanceCfg.isProd;
     env_short_description = instanceCfg.envShortDescription;
   });
   ```
   - Vorteile gegenüber dem bisherigen Heredoc: korrekte JSON-Escapes, kein händisches Quoting, alle Felder automatisch synchron.

**Verify:** `nix-instantiate --parse module.nix` läuft fehlerfrei.

**Done:** module.nix enthält die drei neuen Options, der config.json-Block nutzt `builtins.toJSON`.
