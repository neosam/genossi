# Quick Task 260603-b43 — masked_iban Template-Variable

## Objective

Neue Template-Variable `masked_bank_account` (maskierte IBAN) in E-Mails (minijinja) und Typst-Dokumenten zur Verfügung stellen. Format: erste 2 + letzte 4 Zeichen sichtbar, Mitte mit `•` maskiert, Output in 4er-Gruppen.

Zusätzlich: `group_iban()` Helper als Nebenprodukt, damit künftig auch die unmaskierte IBAN gruppiert dargestellt werden kann.

## Findings — bestehende IBAN-Logik

**Keine bestehende Gruppierungs-/Format-Funktion gefunden.** IBANs werden überall als Plain-String (`String` bzw. `Arc<str>` via `MemberEntity.bank_account`) behandelt:

- `genossi_mail/src/template.rs:35` — `bank_account` als Plain-String im Template-Context
- `genossi_service_impl/src/pdf_generation.rs:1000,1094,1158` — `bank_account` als JSON-String an Typst-Templates
- `genossi_service_impl/src/application.rs:113` — `IBAN: {bank_iban}` in Vereins-Antrags-Template (Vereins-IBAN aus Config, nicht Member-IBAN)
- Frontend: WordPress-Integration und Repayment-Entry-List zeigen IBAN unmodifiziert an

→ Wir bauen `group_iban()` + `mask_iban()` neu in `genossi_service/src/iban.rs` (gemeinsame Basis, beide upstream Crates können importieren).

## Architecture Decision

Ablage des Helpers in `genossi_service` (nicht `genossi_service_impl` oder `genossi_mail`):

- `genossi_mail` → hängt von `genossi_service` ab ✓
- `genossi_service_impl` → hängt von `genossi_service` ab ✓
- `genossi_service_impl` → hängt von `genossi_mail` ab → würde Zyklus erzeugen, falls Helper in `genossi_mail`

`genossi_service` ist neutral und wird von beiden Konsumenten genutzt.

## Tasks

### T1 — Helper-Modul `genossi_service/src/iban.rs`

- `pub fn group_iban(iban: &str) -> String` — entfernt Whitespace, gruppiert in 4er-Blöcke
- `pub fn mask_iban(iban: &str) -> String` — erste 2 + letzte 4 sichtbar, Mitte `•`, dann `group_iban`
- Edge Cases:
  - Empty input → `""`
  - Whitespace-only → `""`
  - Länge < 6 Zeichen → komplette Maskierung mit `•` (defensive Approach), dann gruppiert
  - Idempotenz: `group_iban(group_iban(x)) == group_iban(x)`
- Unit-Tests (`#[cfg(test)]`) für alle Edge Cases inkl. Beispiel "DE89370400440532013000" → "DE•• •••• •••• •••• ••30 00" (22 mod 4 = 2 → letzte Gruppe 2 Zeichen)
