<objective>
Add the single canonical German euro formatter `format_eur_de(cents: i64) -> String` to
`genossi_service` and retrofit the existing `send_confirmation_mail` onto it, replacing the
naive inline format that has no thousands separator. This is the shared formatter that the
Phase-30 application-template context (`open_amount`, plan 30-03) and the existing
confirmation mail both route through (D-11, D-12, D-13 / APTPL-02).

Purpose: One correct euro formatter across the whole domain — Tausenderpunkt, Dezimalkomma,
`€`-Suffix, correct Null/Negativ handling — so the offene-Betrag string in the applicant
reminder is right and consistent with the confirmation mail.
Output: `genossi_service::euro::format_eur_de` (pure, tested) + `send_confirmation_mail`
retrofit.
</objective>

    - format_eur_de(123456) == "1.234,56 €"   (thousands separator '.')
    - format_eur_de(100000000) == "1.000.000,00 €"   (multiple groups)
    - format_eur_de(-123456) == "-1.234,56 €"   (sign prefix, cents NOT negative)
    - format_eur_de(-5) == "-0,05 €"
  </behavior>
  <action>
    Create module `genossi_service/src/euro.rs` exposing `pub fn format_eur_de(cents: i64) -> String`.
    Add `pub mod euro;` to `genossi_service/src/lib.rs` next to `pub mod iban;`.
    Algorithm (per D-13 / Pitfall 4): compute `let neg = cents < 0;` then work on `cents.unsigned_abs()`
    (or `cents.abs()` via i128 to avoid i64::MIN overflow); split into `euros = abs / 100` and
    `frac = abs % 100`; render the euro integer part with '.' as thousands separator by grouping
    digits in threes from the right; assemble `"{euros_grouped},{frac:02} €"`; prepend '-' only when
    `neg`. Rust std has no locale formatter — group the thousands manually (do NOT pull a crate;
    "add nothing" holds). Keep the function pure, synchronous, no I/O — mirror the shape and
    doc-comment discipline of `iban::mask_iban`.
    Place unit tests in a `#[cfg(test)] mod tests` covering every vector in <behavior> plus one
    large multi-group value; assert exact string equality including the `€` (U+20AC) and the
    NBSP/space choice — use a plain ASCII space before `€` to match the existing confirmation-mail
    wording ("... von X €").
