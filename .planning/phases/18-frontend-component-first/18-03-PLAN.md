2. **Component-Body anpassen** (Zeilen 50-58) — Lookup-Fallback:
```rust
    // Phase 18 L-5: override-list takes precedence over global MEMBERS.
    let members_state = MEMBERS.read();
    let global_members = &members_state.items;
    let members: &[MemberTO] = match &members_override {
        Some(list) => list.as_slice(),
        None => global_members.as_slice(),
    };

    // Find selected member for display
    let selected_member: Option<&MemberTO> =
        selected_id.and_then(|sid| members.iter().find(|m| m.id == Some(sid)));

    // Filter results
    let filtered = filter_members(members, &query.read(), exclude_id);
```

ACHTUNG: `MEMBERS.read()` muss aufrechterhalten werden (auch wenn `members_override = Some(...)`), weil der `members_state`-Borrow den `global_members`-Reference haelt — andernfalls ergibt sich ein Lifetime-Problem in der match-Arm. Falls Lifetimes Probleme machen, klone die Liste explizit:
```rust
let members_owned: Vec<MemberTO> = match members_override.clone() {
    Some(list) => list,
    None => MEMBERS.read().items.clone(),
};
let members: &[MemberTO] = members_owned.as_slice();
```
(Klein, MAX_RESULTS=10 — Clone-Cost trivial.)
