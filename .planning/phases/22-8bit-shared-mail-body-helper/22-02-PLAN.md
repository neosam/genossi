<objective>
Extract the pure, synchronous MIME construction from `worker.rs::send_mail_for_recipient` into a new shared module `genossi_mail::send` (new file `send.rs`), and redirect both `service.rs` test-mail paths (which the digest inherits) through it. The extracted `build_message` accepts a `MailEncoding` parameter and switches the text part between `quoted-printable` (default) and `8bit` (opt-in) — the ONE place where CTE is decided. Add MIME-byte tests that CALL `build_message` for both encoding modes and cover the previously-untested test-mail/digest path (D-10, D-11).

Purpose: This is the heart of Phase 22. It fixes the `charset=utf-8` bug at all three sites at once (MAIL-01), enables MAIL-02 (8bit CTE), preserves MAIL-05 (default behavior unchanged), and lays the groundwork for Phase 23's `multipart/alternative` HTML rewire — Phase 23 will inject an `html_body: Option<&str>` parameter into `build_message` without another cross-crate refactor.

Output:
- New file `genossi_mail/src/send.rs` with `LoadedAttachment` + `build_message` + MIME-byte tests.
- `genossi_mail/src/lib.rs` gains `pub mod send;`.
- `worker.rs::send_mail_for_recipient` reduced to: load attachment bytes → call `build_message` → `transport.send()` → return `Ok(message_id)`.
- `service.rs::send_test_mail` and `send_test_mail_with_body` reduced to: `load_smtp_config` → `build_transport` → `build_message(..., &[], None, smtp.encoding)` → `transport.send()`.
- Existing worker MIME-tests that today re-inline lettre construction are updated to CALL `build_message` (D-11); the 8bit-mode CTE assertion is new.
</objective>
