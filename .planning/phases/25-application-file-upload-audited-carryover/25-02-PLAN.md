## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Service → DAO | Untrusted-shaped data is expected to have been validated by the caller (Service); DAO layer trusts `ApplicationDocumentEntity` field values but still binds via parameterized queries to defeat SQL injection at the storage boundary. |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-25-02-01 | Tampering | SQLx queries in `application_document.rs` (SQLite impl) | high | mitigate | Use ONLY parameterized `sqlx::query()` / `query_as::<_,_>` with `.bind(...)` — no string interpolation, no `format!(..., SQL)`. Grep gate in acceptance rejects `sqlx::query!` and format-based SQL. |

Service layer (Wave 2) will use `find_active_by_application_id` + branch to `create` OR `update` — never blind create. Grep confirms `CREATE UNIQUE INDEX ... WHERE deleted IS NULL` in migration. |
