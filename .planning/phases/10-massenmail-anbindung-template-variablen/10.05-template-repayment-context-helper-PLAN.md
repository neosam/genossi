**Schritt 1 — PRIMARY-Pfad (context! spread):** Fuege am Ende von `genossi_mail/src/template.rs` (oder nach `render_footer`, vor dem `#[cfg(test)] mod tests`) eine neue oeffentliche Funktion ein:

```rust
/// Phase 10 D-04 (MAIL-02): merge per-recipient repayment-context into a base context.
///
/// Adds three variables to a minijinja context that the Worker pre-computed from
/// RepaymentEntry aggregation + RepaymentPhase lookup:
/// - `payout_amount`: German-localized euro string, format "X,YZ" (e.g. "60,00").
/// - `share_count`: total share count being paid out (i32).
/// - `fiscal_year`: phase.fiscal_year (i32, e.g. 2026).
pub fn merge_repayment_context(
    base: Value,
    payout_amount: &str,
    share_count: i32,
    fiscal_year: i32,
) -> Value {
    context! {
        ..base,
        payout_amount => payout_amount,
        share_count => share_count,
        fiscal_year => fiscal_year,
    }
}
```

**Schritt 1b — FALLBACK-Pfad (BTreeMap-Merge):** Falls `context! { ..base, ... }` NICHT kompiliert (z.B. weil die minijinja-Version den Spread-Operator nicht unterstuetzt oder ein Feature-Flag fehlt), nutze SOFORT diese vollstaendige Fallback-Implementierung — kein Probieren, kein Debug-Loop, einfach ersetzen:

```rust
/// FALLBACK-Variante: wenn context! { ..base, ... } nicht kompiliert.
/// Implementierung baut den merged Value via BTreeMap + Value::from_serialize.
pub fn merge_repayment_context(
    base: Value,
    payout_amount: &str,
    share_count: i32,
    fiscal_year: i32,
) -> Value {
    use minijinja::value::Value as MjValue;
    use std::collections::BTreeMap;

    // Step 1: convert base Value to a BTreeMap<String, serde_json::Value>
    // via serde_json round-trip. minijinja Value supports Serialize since v2.
    let base_json: serde_json::Value = serde_json::to_value(&base)
        .unwrap_or(serde_json::Value::Object(serde_json::Map::new()));
    let mut map: BTreeMap<String, serde_json::Value> = match base_json {
        serde_json::Value::Object(obj) => obj.into_iter().collect(),
        _ => BTreeMap::new(),
    };

    // Step 2: insert the 3 new fields (overwrites base if name clashes — Phase 10
    // accepts that, since the worker only calls this for repayment-flagged jobs).
    map.insert(
        "payout_amount".to_string(),
        serde_json::Value::String(payout_amount.to_string()),
    );
    map.insert(
        "share_count".to_string(),
        serde_json::Value::Number(serde_json::Number::from(share_count)),
    );
    map.insert(
        "fiscal_year".to_string(),
        serde_json::Value::Number(serde_json::Number::from(fiscal_year)),
    );

    // Step 3: convert the merged map back into a minijinja Value
    MjValue::from_serialize(&map)
}
```

**Schritt 3 (D-14 Planner-Discretion — OPTIONAL, INCLUDE):** Erweitere `validate_template` (Z. 71-116) optional um einen Probe-Render mit Dummy-Repayment-Context, wenn der Aufrufer signalisiert dass repayment-Variablen zu erwarten sind.
```rust
/// Phase 10 D-14: Probe-render templates against both Member-context AND a dummy
/// Repayment-context. Catches `{{ payout_amount }}` references without `{% if %}`
/// guards before the worker actually sends mails — fail-fast in REST validation.
///
/// Used by REST send-bulk endpoint when SendBulkMailRequest.repayment_phase_id is Some.
pub fn validate_template_with_repayment(
    subject: &str,
    body: &str,
    members: &[MemberEntity],
) -> Result<(), Vec<String>> {
    // First: pure-member probe (existing behavior + same error format)
    if let Err(errs) = validate_template(subject, body, members) {
        return Err(errs);
    }
    // Then: probe with merged repayment context (dummy values)
    let mut errors = Vec::new();
    let env = strict_env();
    let subject_tmpl = match env.template_from_str(subject) {
        Ok(t) => t,
        Err(e) => { errors.push(format!("Subject syntax error: {}", e)); return Err(errors); }
    };
    let body_tmpl = match env.template_from_str(body) {
        Ok(t) => t,
        Err(e) => { errors.push(format!("Body syntax error: {}", e)); return Err(errors); }
    };
    for member in members {
        let base = member_to_template_context(member);
        let merged = merge_repayment_context(base, "0,00", 0, 2026);
        if let Err(e) = subject_tmpl.render(&merged) {
            errors.push(format!("Subject render error with repayment context for member #{}: {}", member.member_number, e));
        }
        if let Err(e) = body_tmpl.render(&merged) {
            errors.push(format!("Body render error with repayment context for member #{}: {}", member.member_number, e));
        }
    }
    if errors.is_empty() { Ok(()) } else { Err(errors) }
}
```
